CASE STUDY · SOLE ENGINEER · IN PRODUCTION · CLIENT CONFIDENTIAL

From raw satellite signal to centimeter-level answers, daily and unattended.

Some monitoring problems need to know whether a point on the ground moved by centimeters. That demands raw GNSS observation data, careful post-processing, and infrastructure that ingests, computes, archives, and alerts without manual babysitting.

I designed, built, and operate that platform end to end for a client. Specifics are kept general here; happy to go deeper in conversation.

  • STAGE 01
    ACQUIRE
    Field acquisition

    Dual-band GNSS receivers capture raw multi-constellation observations at remote sites. Cellular uplinks move the data out, designed for locations with no fixed connectivity and intermittent power.

    Dual-band GNSSRaw observation dataCellular uplink
  • STAGE 02
    INGEST
    Ingestion & storage

    A Node.js ingestion layer receives daily observation files, validates them, and archives raw data structured for reprocessing: raw signal is never thrown away, so the whole history can be recomputed when processing improves.

    Node.jsTypeScriptCloud object storage
  • STAGE 03
    COMPUTE
    RTK post-processing

    Containerized open-source RTK workloads run on serverless container compute, resolving carrier-phase ambiguities against reference station data to produce centimeter-level position solutions. Compute scales with the job and costs nothing when idle.

    Open-source RTKDockerServerless containers (AWS)
  • STAGE 04
    WATCH
    Monitoring & alerting

    Automated checks verify that every site delivered its expected daily data and raise an email alert the moment a receiver goes quiet. A silent sensor surfaces within hours, not weeks.

    Automated checksEmail alerting

PERSONAL INFRASTRUCTURE · ALWAYS ON

A homelab run like production, because it does production work.

Three Raspberry Pis (models 3, 4, and 5) meshed into a private network with Tailscale, each running Dockerized services organized for clean operations. It's a learning ground for distributed systems, but it also carries real responsibilities.

  • LAYER 01
    NETWORK
    Private mesh

    Tailscale connects every node into a zero-config WireGuard mesh, with HTTPS serving for select services. No exposed ports, no dynamic-DNS fragility, access from anywhere.
